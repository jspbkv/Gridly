# Руководство по подключению Google OAuth и авторизации через Supabase

Полная пошаговая инструкция для настройки аутентификации игроков через Google аккаунт в Supabase с нуля и интеграции с игрой Block Blast.

> [!IMPORTANT]
> **Подтвержденные решения пользователя:**
> - Способ входа: **Только Google OAuth**.
> - SQL-схема и таблицы (`leaderboard`, `player_profiles`) уже успешно созданы в Supabase.
> - Настройка Google Cloud Console: **с нуля (пошаговый гайд)**.

## 1. Настройка Google Cloud Console (С нуля)

### Шаг 1.1: Создание проекта в Google Cloud
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. В верхнем выпадающем меню проектов нажмите **«New Project»** (Новый проект).
3. Введите название проекта (например, `Block Blast Game`) и нажмите **«Create»** (Создать).
4. Убедитесь, что в верхнем меню выбран созданный проект.

### Шаг 1.2: Настройка экрана согласия (OAuth Consent Screen)
1. В левом меню перейдите в **APIs & Services** → **OAuth consent screen** (Экран согласия OAuth).
2. Выберите тип пользователя: **External** (Внешний) и нажмите **«Create»** (Создать).
3. Заполните обязательные поля:
   - **App name** (Название приложения): `Block Blast`
   - **User support email** (Email поддержки): выберите вашу почту Google
   - **Developer contact information** (Email разработчика): введите вашу почту
4. Нажмите **«Save and Continue»** (Сохранить и продолжить).
5. На шаге **Scopes** (Области доступа):
   - Нажмите **«Add or Remove Scopes»**
   - Отметьте базовые области: `.../auth/userinfo.email`, `.../auth/userinfo.profile`, `openid`
   - Нажмите **«Update»**, затем **«Save and Continue»**.
6. На шаге **Test users** (Тестовые пользователи):
   > [!NOTE]
   > Пока проект не опубликован, войти смогут только пользователи из этого списка.
   - Нажмите **«Add Users»** и добавьте свой личный Google email (и email друзей/тестировщиков).
   - Нажмите **«Save and Continue»**.
7. Нажмите **«Back to Dashboard»**.

## 2. Получение Redirect URL из Supabase

1. Откройте панель управления [Supabase Dashboard](https://supabase.com/dashboard).
2. Выберите ваш проект.
3. В левом меню перейдите в раздел **Authentication** → **Providers**.
4. Найдите в списке провайдеров **Google** и разверните его.
5. Скопируйте значение из поля **Callback URL (for OAuth)**.
   - Оно имеет вид: `https://<ВАШ_PROJECT_REF>.supabase.co/auth/v1/callback`.

---

## 3. Создание OAuth Client ID в Google Cloud

1. Вернитесь в Google Cloud Console.
2. В левом меню выберите **APIs & Services** → **Credentials** (Учетные данные).
3. Вверху нажмите **«+ Create Credentials»** → **«OAuth client ID»**.
4. В поле **Application type** (Тип приложения) выберите **Web application** (Веб-приложение).
5. Назовите клиент (например, `Supabase Auth Client`).
6. В блоке **Authorized JavaScript origins** (Авторизованные источники JavaScript):
   - Добавьте URL вашего проекта Supabase: `https://<ВАШ_PROJECT_REF>.supabase.co`
   - Добавьте URL запущенного приложения (из браузера, например `https://ais-dev-...run.app`).
7. В блоке **Authorized redirect URIs** (Авторизованные URI перенаправления):
   - Нажмите **«+ Add URI»** и вставьте скопированный из Supabase **Callback URL**:
     `https://<ВАШ_PROJECT_REF>.supabase.co/auth/v1/callback`
8. Нажмите кнопку **«Create»** (Создать).
9. Появится всплывающее окно с двумя ключами:
   - **Client ID**
   - **Client Secret**
   *(Скопируйте их)*.

---

## 4. Включение Google в Supabase Dashboard

1. Вернитесь в [Supabase Dashboard](https://supabase.com/dashboard) → **Authentication** → **Providers** → **Google**.
2. Включите тумблер **«Enable Google provider»**.
3. Вставьте:
   - **Client ID (for OAuth)**: вставьте ваш Client ID из Google.
   - **Client Secret (for OAuth)**: вставьте ваш Client Secret из Google.
4. Нажмите **«Save»** (Сохранить).
5. Перейдите в раздел **Authentication** → **URL Configuration**:
   - В поле **Site URL** укажите текущий URL игры (например, URL вашего предпросмотра).
   - В **Redirect URLs** добавьте текущий домен игры со звездочкой или точным адресом (чтобы после входа Google вернул игрока прямо в игру).
   - Нажмите **«Save»**.

---

## 5. Подключение ключей в игре Block Blast

В игре уже реализован встроенный интерфейс подключения к вашей базе данных:
1. Запустите игру.
2. Откройте **Настройки (⚙️)** в главном меню или перейдите в **Профиль игрока**.
3. Нажмите на кнопку **«Подключить Supabase»** (или иконку базы данных 🗄️).
4. В появившемся окне введите ваши ключи Supabase:
   - **Supabase Project URL** (берется в Supabase Dashboard: *Settings* → *API* → *Project URL*).
   - **Supabase Anon / Public Key** (берется в Supabase Dashboard: *Settings* → *API* → *Project API keys* → `anon` `public`).
5. Нажмите **«Сохранить и подключить»**. Статус станет зеленым: *«Подключено к Supabase»*.

---

## 6. Тестирование авторизации и синхронизации

1. В игре перейдите в **Профиль** или нажмите на кнопку входа в меню.
2. Нажмите **«Войти через Google»**.
3. Откроется стандартное окно авторизации Google — выберите ваш добавленный тестовый аккаунт.
4. После подтверждения игра автоматически:
   - Подтянет ваше имя и аватар из Google аккаунта;
   - Разблокирует редактирование никнейма и выбор аватарок;
   - Откроет смену тем оформления и звуковые настройки в меню «Настройки»;
   - Откроет полную аналитику и графики в разделе «Статистика»;
   - Автоматически синхронизирует рекорды и отправит их в **Глобальный топ лидеров** (🏆)!
